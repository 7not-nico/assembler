# Compound Aggregator Domains — `_{abstract-noun}/`

The assembler root holds `_{abstract-noun}/` folders as compound aggregator domains. Each folder aggregates projects of its domain; each project inside becomes its own repository, sharing the domain folder as common space.

The assembler repo tracks each domain as a folder placeholder only (`.gitkeep`); contents live in their own repos.

## Domains

```text
_atelier/    creative coding
_codex/      code dives
_knowledge/  knowledge projects
_trove/      research captures
_depot/      depot content
_sandbox/    experiments
```
