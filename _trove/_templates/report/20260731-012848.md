## Findings

```
1. TRANSPORT, NOT LANGUAGE, is the vectorization lever:
   Rust+JSON 0.4× → TS 1.0× → Go+binary 3.8×. The math was never the cost;
   serialization and spawn overhead were
2. Context7 verified the canonical Bun patterns — spawn stdin accepts TypedArray
   directly, readableStreamToArrayBuffer for output — removing the temp-file
   workaround and the fs import entirely
3. Go default + TS fallback keeps correctness parity (verified identical results)
4. Goroutine-parallel scoring (8-bound) scales cleanly with corpus size
5. Rust _rustlib/ now redundant — keep as JSON-protocol reference or archive
```
