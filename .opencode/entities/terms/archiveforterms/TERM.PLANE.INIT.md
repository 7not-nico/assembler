**Init Plane — Project Classification** — measures how much of the AMANDA tooling stack is set up.

**full** — has AGENTS.md + .opencode/ with tools + package.json + DB schema + DB file. Fully initialized.

**partial** — has AGENTS.md but incomplete tooling infra. e.g. generative workflow projects with no tools dir yet.

**flat** — flat markdown only, no code or tooling. Content is documentation/notes.

**none** — no infrastructure. No AGENTS.md, no .opencode/, no content.
