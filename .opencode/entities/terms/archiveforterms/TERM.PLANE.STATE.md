**State Plane — Project Classification** — distinguishes active AMANDA projects from external content, scratch workspaces, and empty dirs.

**live** — active AMANDA project with AGENTS.md and tooling. Has its own domain, data model, and workflow.

**external** — not an AMANDA project. Cloned repos for study, imported content. No AGENTS.md or tooling.

**scratch** — planning workspace with scratch docs and proposals. Not live content. May contain `.bak` files and staging material.

**empty** — not initialized, no content. Placeholder for future use.
