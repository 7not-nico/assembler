**Vocation Plane — Project Classification** — describes the project's purpose and content type.

**study** — tracks learning progress through external sources (textbooks, papers, videos). Sources → concepts → notes workflow. Priorities and status track progress.

**catalog** — structured reference data organized for query. Records are factual and relatively static. Cross-references between entities.

**log** — personal diary entries over time. Each entry has a timestamp and records an event, fix, or spontaneous thought. Append-only.

**tracker** — tracks state changes of real-world objects. Each object has a lifecycle and status transitions.

**wiki** — researched content with cross-references. Guides, specs, decision trees. Content is curated and maintained.

**template** — IaC reference for other projects. The canonical example of project structure and tooling. Other projects derive from this pattern.
