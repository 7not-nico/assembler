**OpenCode Commands** — custom slash-command definitions in `.opencode/commands/` that serve as structured guidance — directed thoughts for recurring agent tasks. Each command is a markdown file whose filename (minus `.md`) defines the `/command` name; invocation provides the agent with a predefined workflow, guardrails, or decision tree for a specific scenario. Commands bridge reference documentation and executable process, encoding domain knowledge into an invocable form that constrains agent behavior toward predictable, high-quality outcomes.
