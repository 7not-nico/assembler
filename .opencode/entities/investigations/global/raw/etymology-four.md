# Etymology: Principle, Heuristic, Maxim, Tenet

**Method**: Cross-regional etymological survey (Latin, Greek, French, German, Anglophone)

---

## The Four Terms

### PRINCIPLE — Latin *principium*

| Element | Detail |
|---------|--------|
| Root | *primus* "first" + *capere* "to take" |
| Compound | *princeps* "first-taker, chief" → *principium* "beginning, foundation" |
| Path | Latin → Old French *principe* → English *principle* (14c) |
| Greek parallel | *archē* (ἀρχή) "beginning, origin, sovereignty, first principle" |
| Kant | *Prinzip* / *Grundsatz* interchangeable = a priori foundational proposition |
| Bentham (1789) | First to explicitly decompose the English word: *primus* + *capio* |
| Root metaphor | **Foundation** — that which is taken first, built upon |

### HEURISTIC — Greek *heuriskein*

| Element | Detail |
|---------|--------|
| Root | PIE *wreh₁- "to find" |
| Greek | εὑρίσκω (heurískō) "to find, discover, devise, invent" |
| Derivations | εὕρημα "find", εὕρεσις "discovery", εὑρετικός "inventive" |
| Archimedes | εὕρηκα "I have found (it)" (c. 287-212 BCE) |
| English | 1821 — irregular formation from Gk *heuriskein* + *-istic* |
| Root metaphor | **Discovery** — active search, not guaranteed optimal |

### MAXIM — Latin *maxima*

| Element | Detail |
|---------|--------|
| Root | *maximus* "greatest" (superlative of *magnus* "great") |
| Full form | *maxima propositio* "greatest premise" (Boethius, c. 500 CE) |
| Path | Latin → Old French *maxime* → English *maxim* (15c) |
| Boethius | Self-evident warrant for topical inference — "greatest among propositions" |
| La Rochefoucauld (1665) | *Réflexions ou Sentences et Maximes morales* — literary genre |
| Kant | *Maxime* = subjective principle of willing (vs objective *praktisches Gesetz*) |
| Root metaphor | **Authority** — the greatest, most general premise |

### TENET — Latin *tenet*

| Element | Detail |
|---------|--------|
| Root | *tenere* "to hold" ← PIE *ten- "to stretch" |
| Form | 3rd person singular present indicative: "he/she/it holds" |
| Path | Medieval Latin doctrinal formula → English (early 15c) |
| *tenent* | 3rd person plural "they hold" — obsolete in English by c. 1725 |
| Noah Webster (1828) | "Any opinion, principle, dogma or doctrine which a person believes or maintains as true" |
| Root metaphor | **Grip/Possession** — a proposition firmly held onto |

---

## Cross-Comparison

| Word | Source | Literal meaning | Root metaphor | Agency | Certainty |
|------|--------|-----------------|---------------|--------|-----------|
| Principle | L *principium* | "first-taking" | **Foundation** | Active (take) | Universal truth |
| Heuristic | Gk *heuriskein* | "to find" | **Discovery** | Active (find) | Fallible |
| Maxim | L *maxima* | "greatest (premise)" | **Authority** | Active (state) | Self-evident |
| Tenet | L *tenet* | "he holds" | **Grip** | Passive (hold) | Group-held belief |

**Key distinction**: Principle (active/universal) → Heuristic (active/fallible) → Maxim (active/authoritative) → Tenet (passive/group-held).
