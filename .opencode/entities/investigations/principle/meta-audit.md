# Meta-Audit: PRINCIPLE

**3 regions PASS**

## Etymological Chain

PIE `*per-` "forward" → *primus* "first" + *capere* "take" → *princeps* "first-taker, chief" → *principium* "beginning, foundation" → OF *principe* → English *principle* (14c)

Greek parallel: *archō* "begin, rule" → *archē* "beginning, first principle, sovereignty"

## Regional Summaries

### Latin — PASS
- *principium* decomposed: *primus* + *capio* = "first-taking"
- Cicero: *principia rerum* "first principles"; *principia naturalia*
- Bentham (1789): first to explicitly decompose the English word
- Root metaphor: **foundation** — that which is taken first, built upon

### Greek — PASS
- *archē*: dual meaning — temporal origin AND sovereign power
- Anaximander introduced *archē* as technical philosophical term (6th C BC)
- Aristotle *Metaphysics* 1013a: six-fold definition
- Root metaphor: **origin/source** — both starting point and ruling principle

### German — PASS
- Kant: *Prinzip* / *Grundsatz* interchangeable = a priori foundational propositions
- *Grundsatz* = "ground-sentence" — the sentence from which all others derive
- Transcendental principles: conditions of possibility of experience

## Core Meaning
**That which is taken first** — a foundational truth from which other truths derive. Universal, objective, pre-supposed.
