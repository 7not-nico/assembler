## Key Findings
- Southeast Asian academic sources focus exclusively on Dijkstra's **algorithm** (shortest path)
- ITB Bandung has notably extensive materials on Dijkstra algorithm for OSPF routing protocol
- Vietnamese sources use "vector" as a C++ STL container without discussing origin
- No discussion of vector terminology origin or OED attribution found

## Gaps
- No Southeast Asian source on Dijkstra's vector coinage
- Regional CS education treats all terminology as established without questioning etymology
