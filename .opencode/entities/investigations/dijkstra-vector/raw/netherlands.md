## Key Findings
- EWD 41 "Het vectorgeheugen" is the **original seminal document** written in Dutch by Dijkstra in 1963 while at the Mathematisch Centrum (now CWI) in Amsterdam
- First paragraph explicitly states: programs request memory as "zoveel aansluitende geheugenplaatsen" (so many consecutive memory locations), which Dijkstra redefines as "**een vector van gegeven lengte**" (a vector of given length)
- The document defines **vector basis** (base address + length), **twijg** (vector of scalars), **tak** (vector of bases), and **parametervector** (for context switching)
- Dutch Wikipedia links to the UT Austin EWD Archive as the authoritative source
- Original was circulated privately (1963), later scanned and transcribed by the E.W. Dijkstra Archive

## Gaps
- Direct Dutch academic papers citing EWD 41 specifically are hard to find online; most contemporary references are from the UT Austin-hosted EWD Archive
- No Dutch university (TU/e, UvA, CWI) has a dedicated analysis page on Dijkstra's vector terminology
