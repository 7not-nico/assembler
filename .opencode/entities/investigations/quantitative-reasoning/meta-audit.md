## 1. Fundamentals

### Definitions

| Source | Definition | Source Type |
|--------|------------|-------------|
| **Steen (2001)** — *Mathematics and Democracy* | QR is a "habit of mind" — predisposition to look at the world through mathematical eyes; anchored in data from the empirical world; as rigorous as pure mathematics | Foundational text (US) |
| **Thompson (1990)** | "An individual's analysis of a situation into a quantitative structure" — encoding real-world situations by recognizing quantitative variables and their relationships | Academic theory (US) |
| **Dana Center (2020)** | "A habit of mind, seeking pattern and order when faced with unfamiliar contexts" — emphasis on data-driven decisions over anecdotal evidence | Curriculum framework (US) |
| **CSU Stanislaus** | "Proficiency and comfort in dealing with and rationally processing numerical data" — includes approximation, models, tables/graphs, algebra, geometry, statistics | University definition (US) |
| **MAA — Bressoud (2023)** | QR requires both encoding (building mathematical models from situations) and solving (applying rules); current instruction overemphasizes solving at expense of encoding | Academic synthesis (US) |

### Core Competency Areas (synthesized across regions)

1. **Encoding / Modeling** — translating unstructured situations into mathematical structures (variables, relationships, equations)
2. **Numerical Fluency** — arithmetic, estimation, approximation, order of magnitude
3. **Algebraic Reasoning** — equations, inequalities, functions, coordinate geometry
4. **Geometric & Spatial Reasoning** — shapes, measurement, visualization
5. **Statistical & Probabilistic Reasoning** — data interpretation, probability, inference
6. **Logical Deduction** — if-then reasoning, necessary/sufficient conditions, argument evaluation
7. **Heuristic Problem-Solving** — Polya's framework: understand, plan, execute, check + strategies

## 3. Gaps

### Region-Level Gaps
| Region | Gap Detail |
|--------|------------|
| East Asia | No labeled "QR" field in native academic discourse; research published under "mathematical thinking" |
| Western Europe | Native-language searches dominated by "quantitative research methodology" — not QR as skill |
| Scandinavia | QR subsumed under PISA mathematical literacy; no independent QR research tradition |
| India | Vast commercial exam prep ecosystem but limited peer-reviewed academic research on QR |
| Russia/EE | Olympiad tradition strong but framed as mathematical problem-solving, not QR |

### Cross-Cutting Gaps
1. **QR vs Mathematical Literacy** — Different regions use different labels (QR, quantitative literacy, mathematical literacy, quantitative aptitude, mathematical thinking) for overlapping concepts; no unified international framework
2. **Encoding vs Solving** — MAA/Bressoud identifies that instruction globally overemphasizes solution procedures over the encoding step (building models from unstructured situations)
3. **Assessment gap** — Standardized tests (GRE, GMAT, CAT) measure QR performance but don't teach the underlying cognitive process
4. **Digital tools** — Emerging research (Springer 2024) on integrating technology into problem-solving but limited practical resources
5. **Pedagogical gap** — Carlson et al. (2023) find instructors default to procedural explanations; training to "speak with meaning" about quantitative relationships is lacking

## 7. Schema

### Regions Table
```sql
CREATE TABLE regions (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    rating TEXT NOT NULL CHECK(rating IN ('PASS','WARN','FAIL')),
    language TEXT NOT NULL,
    dominant_framework TEXT,
    total_sources INTEGER DEFAULT 0
);
```

### Sources Table
```sql
CREATE TABLE sources (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    url TEXT NOT NULL,
    institution TEXT,
    region_id TEXT REFERENCES regions(id),
    type TEXT NOT NULL CHECK(type IN ('academic','official','textbook','curriculum','practice','blog','archive')),
    key_content TEXT,
    methodology TEXT,
    doi TEXT
);
```

### Researchers Table
```sql
CREATE TABLE researchers (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    institution TEXT,
    region_id TEXT REFERENCES regions(id),
    key_work TEXT,
    url TEXT
);
```

### Gaps Table
```sql
CREATE TABLE gaps (
    id TEXT PRIMARY KEY,
    region_id TEXT REFERENCES regions(id),
    description TEXT NOT NULL,
    severity TEXT CHECK(severity IN ('high','medium','low')),
    is_cross_cutting INTEGER DEFAULT 0
);
```

### MetaAnalyses Table
```sql
CREATE TABLE meta_analyses (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    url TEXT,
    year INTEGER,
    scope TEXT NOT NULL,
    key_finding TEXT
);
```
