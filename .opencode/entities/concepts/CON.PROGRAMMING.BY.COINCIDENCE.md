**Programming by Coincidence** — code that works but you cannot explain why. The anti-pattern of relying on accidental behavior rather than deliberate design. Code written by coincidence breaks as soon as the context changes even slightly. The counter-pattern is Programming Deliberately: know what should happen before it does, explain why it happened after.
