**Pragmatic Programmer** — a philosophy of software craftsmanship codified by Andrew Hunt and Dave Thomas in the 1999 book of the same name (20th Anniversary Edition, 2019). The term describes a mindset focused on practical, disciplined software development: taking responsibility for your career, discerning essence from accident, choosing tools and methods that work in context rather than following dogma, and continuously refining both code and process. Core concepts include DRY (Don't Repeat Yourself), Orthogonality, Broken Windows, Tracer Bullets, and Programming Deliberately.
