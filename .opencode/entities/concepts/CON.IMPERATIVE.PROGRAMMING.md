**Imperative Programming** — a programming paradigm that models computation as a sequence of instructions that change program state. The programmer specifies *how* to achieve a result by describing step-by-step operations on mutable storage.

Imperative programming derives from the von Neumann architecture (stored-program computer) where instructions and data share a single memory space. Its core principles: sequential execution (instructions execute in order, with explicit control flow via loops, branches, and jumps), mutable state (variables are named storage locations whose values change over time), and assignment (the fundamental operation that binds a value to a storage location). The paradigm encompasses both structured imperative programming (procedures, blocks, structured control flow) and unstructured forms (assembly, GOTO-based).
