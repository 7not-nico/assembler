**Functional Programming** — a programming paradigm that treats computation as the evaluation of mathematical functions, avoiding mutable state and side effects. Functions are first-class values — they can be assigned, passed as arguments, and returned as results. Computation proceeds through function composition and application rather than sequential instruction execution.

Functional programming is grounded in lambda calculus (Church, 1932) and category theory. Its core principles: referential transparency (expression evaluation depends only on its arguments, not on global state), immutability (data structures are never modified in place), function purity (functions produce no side effects beyond computing their return value), and higher-order functions (functions that accept or return other functions). Common mechanisms include closures, recursion, pattern matching, currying, and algebraic data types.
