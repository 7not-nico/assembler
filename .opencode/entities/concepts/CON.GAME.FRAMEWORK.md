**Game Framework** — category for Ludoteca API entities that represent complete game development frameworks. Distinct from low-level graphics APIs.

Examples: ARCH.API.HEAPS, ARCH.API.ARMORY3D, ARCH.API.HAXEFLIXEL, ARCH.API.LOVE2D. Graphics API category (OpenGL, Vulkan) exposes raw GPU interfaces; Game Framework provides higher-level abstractions (scene graph, physics, input, audio).
