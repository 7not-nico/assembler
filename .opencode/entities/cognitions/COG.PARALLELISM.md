**Parallelism (Computer Science)** — the simultaneous execution of multiple computations using two or more processing elements. Parallelism enables throughput improvement and reduced latency through concurrent task execution on separate hardware units. Amdahl Law bounds speedup by the serial fraction of any computation. Parallel execution implies concurrency. Concurrency and parallel execution are independent properties.
