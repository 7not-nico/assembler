**Linear Algebra** — The mathematical study of vectors, vector spaces, and linear transformations. From Latin *linea* "line" — the algebra of straight lines and the maps that preserve them. A vector is any object that can be scaled and added; a linear transformation is a map between vector spaces that preserves these operations. Matrices represent linear transformations in a chosen basis; matrix multiplication composes transformations.

Linear algebra grounds all machine learning: every neural network layer is a linear transformation followed by a nonlinearity (activation). The attention mechanism in transformers is fundamentally linear algebra — queries, keys, and values are matrices; attention scores are dot products (inner products in a vector space). The classical computer itself is described through linear algebra: the CPU's ALU performs vectorizable operations, memory is a linear address space, and buses transmit vector data.
