**Computer Architecture** — The engineering discipline concerned with the design and organization of computer systems. From Latin *architectura* "chief builder" — the structure and arrangement of components that implements a computing machine. Computer architecture spans the instruction set architecture (ISA — the programmer's view of the machine), microarchitecture (how the ISA is implemented in hardware), and system organization (memory hierarchy, buses, I/O).

Computer architecture grounds the classical computer's design. The von Neumann architecture (stored-program, single shared memory for instructions and data) is the canonical classical architecture. Its components — ALU, control unit, registers, program counter, memory bus, clock — are designed through architectural reasoning about performance (pipelining, caching, branch prediction), power (clock gating, voltage scaling), and cost (transistor count, die size). Computer architecture bridges digital electronics (the gates) and computer science (the programs that run on them).
