**Boolean Algebra** — A two-valued algebraic system over the set {0, 1} with operations AND (∧, conjunction), OR (∨, disjunction), and NOT (¬, negation). Developed by George Boole (1854) in *The Laws of Thought* as a mathematical formalization of logic. Boolean algebra is a complemented distributive lattice — every element has an inverse, and operations distribute over each other.

Boolean algebra grounds the logic of classical computing: every transistor-based logic gate implements a Boolean function. The seven standard gates (AND, OR, NOT, NAND, NOR, XOR, XNOR) each express one Boolean function. Boolean algebra proves that NAND alone (or NOR alone) is functionally complete — any Boolean function expressible from that one gate. This is the mathematical foundation of the classical computer's digital logic layer.
