**Entity Discernibility** — each ID segment narrows identity space until the entity becomes unique.

## Segments

- **PREFIX** — *differre* "carry apart" — differentia, separates entity types
- **DOMAIN** — *distinguere* "prick apart" — distinct, separates functional areas
- **SUBJECT** — *cernere* "sift apart" — discrete, separates topics
- **ASPECT** — *determinare* "bound completely" — determinant, final boundary

## Rules

- PREFIX carries the requirement — each prefix maps to exactly one entity type
- Segment count per ring group appears in SPEC.ENTITY.SEGMENT.COUNT
- Renames that change segment count are valid when prior segments leave ambiguity

## Applicability

All patlib entities. Also `CMD.{VERB}.{DOMAIN}` where VERB is a differentia and DOMAIN a distinct.
