**Entity Discernibility** — each ID segment narrows identity space until entity uniquely determined.

## Segments

- **PREFIX** — *differre* "carry apart" — differentia, entity type separation
- **DOMAIN** — *distinguere* "prick apart" — distinct, functional area separation
- **SUBJECT** — *cernere* "sift apart" — discrete, topic separation
- **ASPECT** — *determinare* "bound completely" — determinant, final boundary

## Rules

- PREFIX required — each prefix maps to exactly one entity type
- Segment count per ring group defined in SPEC.ENTITY.SEGMENT.COUNT
- Renames that change segment count are valid when prior segments leave ambiguity

## Applicability

All patlib entities. Also `CMD.{VERB}.{DOMAIN}` where VERB is a differentia and DOMAIN a distinct.
