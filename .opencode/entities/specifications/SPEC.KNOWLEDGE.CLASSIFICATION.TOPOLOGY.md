**Knowledge Classification** — five topological spaces with ordinal rings. Each group has its own ring topology. Axiomatic entities are the formal foundation. Composition entities form the morphism pipeline.

## Groups

### Axiomatic

```
Ring 0: Maxim, Precept, Specification
Ring 1: Identity
Ring 2: Abstraction, Algorithm, Linguistic
```

- Maxims are orthogonal — no `precedes` between maxims, abstraction formalizes mathematical concepts, algorithm specifies mathematical procedures, linguistic encodes notation and language semantics.

### Encyclopedic

```
Ring 0: Etymology
Ring 1: Cognition
Ring 2: Concept, Definition, Corpus
Ring 3: Term
Ring 4: Specialty
```

- Encyclopedic source points to the closest preceding entity — same ring when the chain continues, inner ring when the chain ends.

### Composition

```
Ring 0: Protocol
Ring 1: Pattern
Ring 2: Nexus
Ring 3: Illustration, Reference
```

- Protocol precedes Pattern, Pattern precedes Nexus, the morphism pipeline: protocol describes, pattern prescribes, nexus composes, illustration documents.

### Architectonic

```
Ring 0: Tool
Ring 1: Command, Skill
Ring 2: Rule

```

- Tool is the executable primitive, Command and Skill compose tools into workflows, Rule governs commands and skills.

### Chronicle

```
Ring 0: Person
Ring 1: Investigation, Apologia, Manifest
Ring 2: Archive, Note
```

- Chronicle source points to any ring of any other grouping.
