**Catalyst for Change** — do what you can with what you have; imperfect but existing beats perfect but specified.

## Action

- **Available resources** — start with what you have, ship the smallest useful version
- **Partial solution** — ships immediately, unblocks downstream work
- **Perfection** — deferred; not abandoned

## Rules

- Ship the smallest useful version before the perfect version
- If a partial solution unblocks downstream work, ship it
- Create ideal conditions with what you have — ship with available resources
- A tool that works at 80% and exists today beats one at 100% that ships next quarter
- Perfection deferred is better than perfection abandoned

## Applicability

Any project where analysis paralysis, dependency chains, or ideal-condition thinking blocks progress.
