**Pattern** — a morphism design entity of the Composition group, Ring 1. Patterns prescribe how the system morphs — transform, recognize, generate, synchronize — using automata theory classes (RECG, TRNS, GENR, SGNL). Each pattern declares its morphism design in a `morphism:` field with corollary rules and applicability. Preceded by Protocols (Composition R0). Precedes Nexus (Composition R2). May be illustrated. Unlike Maxim (Axiomatic R0, universal truth, external source), Pattern describes a system morphism (Composition R1, assembler source).
