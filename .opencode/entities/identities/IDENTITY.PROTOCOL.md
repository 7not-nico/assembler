**Protocol** — a technical contract entity of the Composition group, Ring 0. Protocols state enforceable contracts: schema, field definitions, content conventions, enforcement mechanism, and applicability. Each protocol carries a `protocol:` frontmatter field stating the core contract and an `enforcement:` field (Sealed, Accord, or Formality). Preceded by Axiomatic entities (SPEC/MAX/PRE) which provide the classification, truths, and behavioral rules that protocols implement. In the morphism pipeline: protocol contracts, pattern prescribes, nexus composes.
