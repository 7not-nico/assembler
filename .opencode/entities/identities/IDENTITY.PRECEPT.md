**Precept** — an authoritative behavioral rule entity encoding a practice-derived system directive. Each precept encodes a binding rule in a concise `precept:` statement, derives corollaries in declarative bullet form, and omits concrete examples. Precepts are system-specific — they prescribe how this system operates. Source is always `assembler`.
