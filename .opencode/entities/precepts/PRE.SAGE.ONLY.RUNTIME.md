**SageMath Only** — mathematics and physics use SageMath only.

## Corollaries

- Mathematics, physics, and scientific computing use SageMath only — no Julia, no Python
- Plots use sage.plot primitives only — no matplotlib
- SageMath Jupyter kernel is the primary interface

## Applicability

All mathematics and physics in assembler.
