# Harness Engineering Papers Summary

## 1. Meta-Harness: End-to-End Optimization of Model Harnesses
- **arXiv:** https://arxiv.org/abs/2603.28052
- **Authors:** Yoonho Lee
- **Key Contribution:** Introduces systematic harness evolution with observability, achieving 77.0% pass@1 on Terminal-Bench 2, surpassing human-designed Codex harness.
- **Summary:** Presents a framework where each edit is a falsifiable contract, enabling autonomous harness evolution and transfer across model families.

## 2. Harness Engineering: Making AI Coding Agents Work in 2026
- **Source:** Faros AI Blog (2026-07-15)
- **Link:** https://www.faros.ai/blog/harness-engineering
- **Summary:** Discusses the “senior engineer tax,” review fatigue, and how harness design affects production code quality and safety.

## 3. Harness engineering: leveraging Codex in an agent-first world
- **Source:** OpenAI Blog (2026-02-11)
- **Link:** https://openai.com/index/harness-engineering
- **Summary:** Outlines OpenAI’s harness engineering concepts, emphasizing repository knowledge as system of record and increasing agent legibility.

## 4. Agentic Harness Engineering: Observability-Driven Automatic Evolution of Coding-Agent Harnesses
- **arXiv:** https://arxiv.org/abs/2604.25850 (April 2026)
- **Authors:** Jiahang Lin, Shichun Liu, Chengjun Pan, et al.
- **Key Contribution:** Provides AHE framework with observable edits and predictions, achieving +5.1 to +10.1 percentage points improvement on Terminal-Bench 2.
- **Summary:** Demonstrates that component observability and falsifiable contracts lead to reliable harness evolution.

## 5. Agent Harness Engineering: A Survey
- **Source:** OpenReview (2026-05-14)
- **Link:** https://openreview.net/pdf?id=eONq7FdiHa
- **Summary:** Surveys over 170 open-source projects, mapping harness engineering practices and establishing a three-phase engineering evolution.

## 6. What Is Harness Engineering AI? The Definitive 2026 Guide
- **Source:** Atlan.com (2026-04-13)
- **Link:** https://atlan.com/know/what-is-harness-engineering/
- **Summary:** Defines harness engineering as the control system layer for AI agents, covering the Agent = Model + Harness formula and data layer importance.
