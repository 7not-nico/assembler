# Ruby Float

`Float` represents a double-precision 64-bit IEEE 754 floating-point number.

## Creation

```ruby
1.0           # 1.0
1.5e2         # 150.0  — scientific notation
1.5e-2        # 0.015
3.14          # 3.14
Float(3)      # 3.0    — conversion
```

## Constants

```ruby
Float::EPSILON     # machine epsilon
Float::INFINITY    # +Infinity
Float::NAN         # Not a Number
Float::MAX         # max finite float
Float::MIN         # min positive normalized
Float::RADIX       # 2 — base of exponent
Float::ROUNDS      # rounding mode
```
