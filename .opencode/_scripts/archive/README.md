# archive/

Deprecated scripts and stale reports. Files here are kept for reference but not run.

## Rules

- Move deprecated `r*.rb` scripts here, do not delete
- Move stale `report/*.txt` files here when regenerating
- Prefix renamed scripts with their old name for traceability
- Stale entity files (deprecated PROT.*, RUL.*) archived here
- Redundant commands (.md + .yaml) archived here
- `_backups/` — consolidated legacy backup snapshots (250 files, 1.1M)
- No active code lives here
