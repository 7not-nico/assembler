**Illustration** — a walkthrough file that traces a single concrete instance of a pattern or protocol. Illustrations show how a principle applies to a real case by naming specific entities, file paths, functions, and code. The `illustrates:` frontmatter field links the walkthrough to its illustrated entity. The four-section body (Context, Walkthrough, Key insight, See also) provides a predictable structure for any domain.
