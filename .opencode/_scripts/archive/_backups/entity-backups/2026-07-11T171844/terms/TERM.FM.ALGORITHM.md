**FM Algorithm** — hardwired operator routing matrix in FM synthesis. Preset topology configuring each operator as carrier (audio output) or modulator (phase input to another operator). DX7: 32 fixed algorithms built from 12 unique building blocks. Topology classes: stack (serial modulation chain), branch (parallel modulators to single carrier), root (single modulator to multiple carriers), carrier-only (additive mode, algorithm #32). Feedback loop on operator 6 in every algorithm, scaled 0–7. Algorithm #1: maximum modulation depth (deep cascade). Algorithm #32: zero modulation (all carriers, additive).
