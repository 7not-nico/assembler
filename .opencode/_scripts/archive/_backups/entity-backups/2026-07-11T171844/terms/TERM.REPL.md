**REPL** — Read-Eval-Print Loop, an interactive programming environment that reads user input, evaluates it as code, prints the result, and loops. Canonical formulation: `(loop (print (eval (read))))`. Foundational to scripting languages, command-line shells, and interactive development environments. Originated in Lisp (Deutsch & Berkeley 1964, PDP-1). Taught as the first interactive programming paradigm in CS curricula worldwide.
