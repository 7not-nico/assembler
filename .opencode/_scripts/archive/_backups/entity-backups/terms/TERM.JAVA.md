**Java** — a compiled, object-oriented, class-based programming language developed by James Gosling at Sun Microsystems in 1995. Designed around the principle of "write once, run anywhere" — Java source code compiles to platform-independent bytecode executed by the **Java Virtual Machine**. Standardized under the **Java Community Process** (JCP) as **Java Standard Edition** (Java SE). Features include automatic garbage collection, strong static typing, exception-based error handling, and a comprehensive standard library. Runs on over three billion devices according to Oracle — spanning servers, desktops, mobile (Android), embedded systems, and enterprise infrastructure.
