**PDF** (Portable Document Format) — a final-form document representation format standardized as **ISO 32000**. Created by Adobe Systems in 1993 as a proprietary format; PDF 1.7 was adopted as ISO 32000-1:2008; current version is **PDF 2.0** (ISO 32000-2:2020). Renders documents independently of software, hardware, and operating system — preserving layout, fonts, images, and vector graphics. Built on a PostScript-derived imaging model. Supports annotations, form fields, digital signatures, encryption, accessibility tags (PDF/UA), and subsets for specific domains: **PDF/X** (prepress), **PDF/A** (archival), **PDF/E** (engineering), **PDF/VT** (variable data printing). Media type: `application/pdf`.
