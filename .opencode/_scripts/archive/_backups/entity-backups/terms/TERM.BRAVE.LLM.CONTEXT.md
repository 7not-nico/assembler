**Brave LLM Context API** — Brave's search endpoint optimized for AI agents, LLM grounding, and RAG pipelines. Returns pre-extracted content (text, tables, code) with configurable token budgets, relevance threshold modes, and Goggles-based source ranking. Designed for machine consumption rather than human display. Available through the Web Search bundle at $5/mo. Its documentation at `api-dashboard.search.brave.com` is the authoritative reference — not memory, nor external sources.
