**JVM** (**Java Virtual Machine**) — an abstract computing machine that serves as the runtime engine for the Java platform. Executes Java bytecode stored in the `.class` file format, enabling platform independence through the "write once, run anywhere" principle. Specified by **The Java Virtual Machine Specification** (Java SE Edition). Manages memory through an automatic garbage-collected heap, maintains per-thread stacks for method invocation, and enforces type safety through bytecode verification. Supports multiple languages beyond Java, including Kotlin, Scala, Clojure, and Groovy — all compile to JVM bytecode.
