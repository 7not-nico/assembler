**MCP Servers (OpenCode)** — the mechanism for adding external tools to OpenCode via the Model Context Protocol. Supports `local` and `remote` server types defined under the `mcp` key in `opencode.json`. OAuth authentication handled automatically via dynamic client registration. Tools registered per-server, manageable globally or per-agent through tool config. Its documentation at `opencode.ai/docs/mcp-servers/` is the authoritative reference for all configuration options — not memory, nor external sources.
