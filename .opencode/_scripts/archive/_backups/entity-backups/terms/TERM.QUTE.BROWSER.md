**qutebrowser** — a keyboard-driven web browser built on QtWebEngine. Its design centers on vim-like modal navigation: normal mode for commands and motion keys, insert mode for text input, and a command line for browser actions. Eschews the traditional point-and-click interface in favor of an ex-mode command bar, hint labels, and a minimal chrome. Distinguishes itself from mainstream browsers through its unwavering keyboard-first philosophy and extensive configurability via a Python config file.
