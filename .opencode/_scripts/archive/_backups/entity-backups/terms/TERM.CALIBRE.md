**Calibre** — a free, open-source e-book library management application developed by Kovid Goyal. Cross-platform (Linux, Windows, macOS) — manages, views, converts, edits, and catalogs e-books across major formats (EPUB, Kindle/AZW3, PDF, and others). Features include metadata fetching, newspaper download and conversion, a built-in e-book viewer with dictionary lookup and read-aloud, a content server for remote access, device synchronization, and a code editor for direct e-book modification. Licensed under GNU GPLv3. Written in Python with a Qt-based GUI. Repository hosted at github.com/kovidgoyal/calibre.
