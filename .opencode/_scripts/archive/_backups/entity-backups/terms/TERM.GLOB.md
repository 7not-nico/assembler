**glob** — a pattern-matching syntax for file paths using wildcard characters. Its primitives: `*` matches any sequence of characters, `?` matches any single character, `[...]` matches a character set. Originates from the Bell Labs Unix `glob` command (short for "global"). Serves as the standard for file matching across shells (Bash, Zsh), build tools, and programming languages via libraries like `fast-glob`, `glob` (Node.js), and `path.Glob` (Go).
