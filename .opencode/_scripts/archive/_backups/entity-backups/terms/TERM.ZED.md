**Zed** — a high-performance code editor built in Rust by the former Atom team. Its architecture: GPU-accelerated rendering, a persistent background server (the Zed Futures), and a collaborative multi-player protocol. Prioritizes low-latency editing, language-aware intelligence, and AI-assisted workflows. Shares lineage with the IDE category but distinguishes itself through its native-compiled core and client-server model.
