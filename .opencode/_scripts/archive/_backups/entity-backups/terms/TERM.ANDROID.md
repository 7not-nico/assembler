**Android** — an open-source, Linux-based operating system and software stack created by **Google** under the **Android Open Source Project** (AOSP). Designed for devices with varying form factors — phones, tablets, wearables, TVs, automobiles, and embedded devices. Core architecture comprises a Linux kernel, hardware abstraction layer (HAL), native C/C++ libraries, the **Android Runtime** (ART) executing DEX bytecode, and a Java API framework. Source code licensed primarily under Apache 2.0. The Android Compatibility Program defines a baseline implementation compatible with third-party apps from Google Play. First released in 2008; powers over three billion active devices worldwide.
