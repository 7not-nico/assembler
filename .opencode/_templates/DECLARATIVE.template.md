**The declarative sentence**

Subject leads. An active finite verb follows. The object completes the statement. Each sentence carries one core fact; qualifiers follow the core. Function words stay; prose retains articles, conjunctions, and prepositions.

**Five checks per sentence**

1. Subject leads — the actor occupies the first position
2. Verb acts — the active finite verb follows the subject directly; action verbs state behavior
3. Nouns name — root nouns denote objects and concepts; nominalizations (-tion, -ment, -ity) carry labels only
4. Core first — one fact per sentence; qualifiers follow
5. Assertions state — prose excludes modal hedges (would, could, might, may)
