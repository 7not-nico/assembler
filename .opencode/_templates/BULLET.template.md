**The junction bullet**

Each bullet states one fact. The line opens with its subject; the verb follows. Bullets inside a heading group join; headings compose in order. Plain lines carry the facts; bold marks section headers. Function words stay when they clarify the join.

**Five checks per bullet**

1. One fact per bullet — the line states a single junction
2. Subject opens — the actor occupies the first position
3. Verb joins — the active finite verb links the line to the next
4. Headings group — related bullets sit under one `##` heading
5. Chain flows — bullets sequence; the document reads as a chain

**Transformation — target leads**

```text
Junction bullet                      instead of
Ripgrep searches the directory       searching the directory is what ripgrep does
It respects .gitignore rules         .gitignore rules are respected
Scripts read --json output           the JSON output gets read by scripts
Headings group related bullets       related bullets are grouped under headings
```
