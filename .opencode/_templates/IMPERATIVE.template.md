**The imperative directive**

Verb leads. The object follows. Qualifiers trail after the dash. Each directive states one action. Directives frame what TO do; the target action leads.

**Five checks per directive**

1. Lead with the verb — the command verb occupies the first position
2. Name the object — the directive states its target directly
3. Frame positively — positive directives carry the instruction weight; excluded forms name the target state
4. Keep one action per directive — each step states one action; qualifiers follow
5. Let the state name the rule — the target state carries the label; excluded forms stay unstated

**Transformation — target leads**

```text
Imperative form              instead of
Read the skill file          the skill file requires reading
Run the probe script         the probe script should be run
Write the report             do not forget the report
Keep steps atomic            steps should stay combined
```
