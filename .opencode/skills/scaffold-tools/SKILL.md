**Procedure**

**1. Verify prerequisites** — `/db-domain`, `/db-entities`, `/db-properties` must have run first; `.opencode/manifests/domain.md`, `entities.md`, `properties.md` must exist; `.opencode/schemas/db.sql` must exist

**2. Delegate to command** — delegate to `/scaffold-tools` (`.opencode/commands/scaffold-tools.md`)
- Pass `$ARGUMENTS` as the project directory name
- Command reads manifests, reads schema, generates lib modules, shebang CLI tools, AGENTS.md, package.json, .gitignore, and node_modules symlink

**3. Verify** — run `bun run .opencode/tools/read-{entities}.ts` to confirm tools execute. Run root `verify-deps` to confirm symlink resolves

**Gotchas**

- Prerequisites must exist before delegation — missing manifests or schema cause generation errors
- All generated `.ts` files include contract blocks per `PROT.LIB.CONTRACT`
- Tools use shebang CLI format per `PROT.TOOL.MODEL` — Custom IPC is for root tools
- Standard PRAGMAs (WAL, foreign_keys) in every `initDB()` per `REF.SCHEMA.DATABASE.PRAGMA`
- `node_modules` uses symlink to root per `REF.TOOL.NODE_MODULES.SHARED`
- WAL sidecar files (`-wal`, `-shm`) are transient — `.gitignore` is generated by the command
- State-profile is hybrid: reads manifests (stateless) then triggers write (stateful)

**Rules**

- Prerequisites checked before delegation — step 1 is mandatory
- Delegation to `/scaffold-tools` command is the single execution path — inline generation excluded
- Step 3 is mandatory — verify generated tools before declaring done
