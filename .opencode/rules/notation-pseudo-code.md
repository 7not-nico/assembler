Symbols replace descriptive phrases.

Scope: block-level. Symbols replace descriptive phrases.

`→` — directional flow; use instead of "then", "produces", "leads to"

`::` — type or membership; use instead of "is of type", "has kind"

`=` — assignment; use instead of "equals", "is set to"

`~` — loose association; use instead of "approximately", "related to"

`>>` — dependency; use instead of "depends on", "requires"

Composes with `RUL.WRITING.CONVENTION` — one of 22 writing conventions.
