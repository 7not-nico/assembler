Prose mode uses the full set of communication principles (SOV, function words, finite verbs, declarative statements, active voice). Notation mode uses compressed conventions (lambda linguistics, left-edge deletion, asyndeton, zero copula, gapping, domain-zero anaphora).

Scope: session-level. Mode determined by context:
- Prose mode — user-facing explanations, instructions, declarative knowledge, and running text
- Notation mode — code identifiers, chains, status labels, event names, internal system communication, and compact references

Composes with `RUL.COMMUNICATION.SYSTEM` — one of 12 communication principles; bridge constraint reconciling the family.

Reconciles `RUL.LAMBDA.LINGUISTICS`: subject.object.action notation for code identifiers and chains; SOV for prose sentences.

Reconciles `RUL.LEFT.EDGE.DELETION` and `RUL.ASYNDETON`: function-word deletion for notation mode; full function-word retention for prose mode.

Reconciles `RUL.ZERO.COPULA`: copula deletion for compact labels and status markers; finite verb retention for complete sentences.

Reconciles `RUL.GAPPING` and `RUL.DOMAIN.ZERO.ANAPHORA`: verb omission and domain compression for parallel notation chains; full verb and domain repetition for prose clarity.
