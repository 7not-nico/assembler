Prose mode uses the full set of communication principles (SOV, function words, finite verbs, declarative statements, active voice). Notation mode uses compact conventions (lambda linguistics, left-edge deletion, asyndeton, zero copula, gapping, domain-zero anaphora).

Scope: session-level. Context decides the mode:
- Prose mode — user-facing explanations, instructions, declarative knowledge, and continuous text
- Notation mode — code identifiers, chains, status labels, event names, internal system communication, and compact references

Composes with `RUL.COMMUNICATION.SYSTEM` — one of 13 communication principles; bridge constraint that reconciles the family.

Reconciles `RUL.LAMBDA.LINGUISTICS`: subject.object.action notation for code identifiers and chains; SOV for prose sentences.

Reconciles `RUL.LEFT.EDGE.DELETION` and `RUL.ASYNDETON`: function-word deletion marks notation mode; prose mode keeps every function word.

Reconciles `RUL.ZERO.COPULA`: copula deletion marks compact labels and status markers; complete sentences keep finite verbs.

Reconciles `RUL.GAPPING` and `RUL.DOMAIN.ZERO.ANAPHORA`: parallel notation chains omit verbs and compress domains; prose repeats full verbs and domains for clarity.
