# cite-versioned-docs.md

Docs are versioned — cite the version, not just the page.

## Rule

Every note cites which mise version it reflects:
- Default = latest release (e.g. 2026.7.0)
- Versioned releases: 2026.x.y scheme (year.month.patch)
- Deprecations dated: Tera template functions removed in 2027.5.0; `env_file`/`dotenv`/`env_path` removed in 2027.4.0

Config files change across versions — flag version in note body.

## Practice

Note header format: `**Source:** URL (date), version` — e.g. `https://mise.jdx.dev/configuration/ (2026-07-31), 2026.7.0`.
