# prefer-official-reference.md

Official mise docs first — mise.jdx.dev is the authoritative source.

## Rule

Study claims from official sources before third-party material:
- `mise.jdx.dev` — primary (versioned, 2026.7.0)
- `github.com/jdx/mise` — source, schema, discussions
- `mise-versions.jdx.dev` — tool version registry
- `docs.rs/crate/mise` — crate README

Blogs, mac install guides, dev.to — last resort. Cross-check each claim against official docs.

## Order

1. Official docs page
2. GitHub (schema, source)
3. Registry pages
4. Third-party tutorials
