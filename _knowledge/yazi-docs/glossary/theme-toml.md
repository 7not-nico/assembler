# theme.toml

theme.toml is the color scheme configuration file of Yazi.

Sections style every component: `[app]`, `[mgr]`, `[indicator]`, `[tabs]`, `[mode]`, `[status]`, `[which]`, `[confirm]`, `[spot]`, `[notify]`, `[pick]`, `[input]`, `[cmp]`, `[tasks]`, `[help]`, `[filetype]`, `[icon]`. Styles use `{ fg, bg, bold, ... }` tables. `[flavor]` selects ready-made themes (dark/light) from yazi-rs/flavors.
