# yazi.toml

yazi.toml is the general configuration file of Yazi — manager layout, preview, openers, tasks, plugins.

Located at `~/.config/yazi/yazi.toml` (Unix) or `%AppData%\yazi\config\yazi.toml` (Windows). Sections: `[mgr]`, `[preview]`, `[opener]`, `[open]`, `[tasks]`, `[plugin]`, `[input]`, `[confirm]`, `[pick]`, `[which]`. Options override shipped defaults; `YAZI_CONFIG_HOME` relocates the config dir.
