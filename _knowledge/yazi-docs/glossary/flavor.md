# flavor

A flavor is a ready-made theme package for Yazi.

Installed via `ya pkg add yazi-rs/flavors:{name}`; selected in `theme.toml` under `[flavor]` with `dark` and `light` entries. Flavors carry their own `tmtheme.xml` syntax-highlighting themes — `syntect_theme` unavailable while a flavor is active. Official repo: yazi-rs/flavors.
