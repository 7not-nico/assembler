# prefer-official-reference.md

Official Yazi docs first — yazi-rs.github.io is the authoritative source.

## Rule

Study claims from official sources before third-party material:
- `yazi-rs.github.io/docs` — primary (versioned, 26.5.6)
- `github.com/sxyazi/yazi` — source, preset configs (`shipped` tag)
- `github.com/yazi-rs/plugins`, `/flavors` — official plugin/theme repos
- `awesome-yazi` — community catalog (secondary)

Blogs, gists, tutorials — last resort. Cross-check each claim against official docs.

## Order

1. Official docs page
2. Official GitHub (preset configs, plugins)
3. Community repos / awesome-yazi
4. Third-party tutorials
