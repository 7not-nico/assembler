# cite-versioned-docs.md

Docs are versioned — cite the version, not just the page.

## Rule

Every note cites which docs version it reflects:
- Default = latest release (e.g. 26.5.6)
- `nightly` available for dev docs
- Package manager changed at 26.x: `ya pack` deprecated → `ya pkg`

Config files differ across versions — flag version in note body.

## Practice

Note header format: `**Source:** URL (date), version` — e.g. `https://yazi-rs.github.io/docs/configuration/overview/ (2026-07-31), 26.5.6`.
