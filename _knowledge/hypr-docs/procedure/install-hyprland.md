# install-hyprland.md

**Composes with:** precept/prefer-official-reference.md, precept/cite-versioned-wiki.md

Install Hyprland from official sources. Steps reference wiki.hypr.land/Getting-Started/Installation.

## Prerequisites

1. Determine distribution package availability:
   - Arch: `hyprland` package (extra repo)
   - NixOS: `programs.hyprland.enable = true` (nixpkgs)
   - Other: distro packages or build from source
2. Verify GPU drivers — NVIDIA requires special setup (wiki `/Nvidia/`)
3. Confirm Wayland-capable session (login shell, not X session)

## Install

4. Install the `hyprland` package via distro manager
5. Verify install: `hyprctl version` (prints flags, commit, branch)
6. Install recommended companion packages:
   - `pipewire` + `wireplumber` (NOT pipewire-media-session)
   - `qt5-wayland` + `qt6-wayland`
   - `noto-fonts` (+ Nerd Font for icons)
   - notification daemon (`mako`, `dunst`, or similar)
   - `xdg-desktop-portal-hyprland`
   - auth agent: `hyprpolkitagent`
   - `uwsm` or systemd session wrapper

## Configure

7. Create `~/.config/hypr/hyprland.lua` (auto-generated on first run if absent)
8. Remove `hl.config({ autogenerated = true })` line to clear warning
9. Set monitors: `hl.monitor({...})` per display; `hyprctl monitors all` lists names
10. Add binds, rules, autostart per notes ch03-ch04, ch14

## Launch

11. Start from tty (shell profile):
    ```sh
    if uwsm check may-start; then exec uwsm start hyprland.desktop; fi
    ```
    or `start-hyprland` wrapper (crash recovery + safe mode)
12. On first launch: confirm binds work, window rules apply, autostart fires

## Verify

13. `hyprctl clients` — windows listed
14. `hyprctl monitors` — outputs correct
15. `hyprctl workspace` — navigation works
16. Save-triggered reload: edit config, confirm live reload without restart
