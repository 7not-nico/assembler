# ch11-wallpapers.md

**Source:** wiki.hypr.land/Useful-Utilities/Wallpapers/ (2026-07-29), Playwright snapshot

Launch wallpaper utility with hyprland config autostarts.

```
| Utility | Type | Notes |
|---------|------|-------|
| **hyprpaper** | first-party daemon | from Hypr Development team; usage/config at Hypr-Ecosystem/hyprpaper |
| swaybg | simple static wallpaper | github.com/swaywm/swaybg |
| wpaperd | advanced daemon | automatic wallpaper changing (github.com/danyspin97/wpaperd) |
| mpvpaper | video wallpaper | mpv wrapper (github.com/GhostNaN/mpvpaper); mpvpaper-stop pauses in background to save resources/battery |
| awww | animated wallpaper daemon | runtime-controlled, no restart needed (codeberg.org/LGFae/awww) |
| waypaper | GUI wallpaper manager | visual pick, static/animated; backends swaybg + awww (github.com/anufrievroman/waypaper) |
| wallrizz | TUI wallpaper manager | visual pick + apply; backends awww, hyprpaper, more (github.com/5hubham5ingh/WallRizz) |
```
