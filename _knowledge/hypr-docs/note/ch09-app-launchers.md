## First-party

**Hyprlauncher** — multipurpose launcher/picker for Hyprland (first-party). Usage/config at `Hypr-Ecosystem/hyprlauncher`.

## Launcher catalog

```
| Launcher | Type | Notes |
|----------|------|-------|
| Wofi | GTK launcher | SourceHut: hg.sr.ht/~scoopta/wofi |
| Rofi | window switcher + app launcher + dmenu replacement | Wayland support since 2025 (github.com/davatorium/rofi) |
| bemenu | Wayland-native dmenu replacement | github.com/Cloudef/bemenu |
| HyprTile | Mega-Launcher for Hyprland | app grid, per-app config, music search, notes, screenshot/recording, system monitor, volume control, starfield bg (hyprtile.org) |
| fuzzel | launcher for wlroots compositors | similar to rofi `drun` mode (codeberg.org/dnkl/fuzzel) |
| tofi | fast dmenu/rofi replacement | single-frame on-screen when configured correctly (github.com/philj56/tofi) |
| Emacs | app launcher via emacs server | DistroTube's configuring-emacs, SebastienWae/app-launcher |
| anyrun | Wayland-native krunner-like runner | modular, plugin-extensible; Applications Plugin for app launching (github.com/anyrun-org/anyrun) |
| **walker** | extensible Wayland-native runner | built-in modules: applications, runner, hyprland windows, websearch; service mode for faster startups (github.com/abenz1267/walker) |
| vicinae | C++/Qt native launcher | runs as background server; raycast extension compatibility layer (github.com/vicinaehq/vicinae) |
```

## Notes

- Comprehensive launcher list: `awesome-hyprland#runners-menus-and-application-launchers`
- Walker — the runner of note for this system's ecosystem (waybar/walker/mako/kitty integration target)
