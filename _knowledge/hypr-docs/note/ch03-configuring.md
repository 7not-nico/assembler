## Config model (Lua since 0.55)

- Config at `$XDG_CONFIG_HOME/hypr/hyprland.lua` → `~/.config/hypr/hyprland.lua`
- Override: `--config` / `-c` argument
- Auto-generates example config if none exists (`hl.config({ autogenerated = true })` line → remove to clear yellow warning)
- **Live reload** — reloads the moment file saves; manual: `hyprctl reload`
- Example config: `github.com/hyprwm/Hyprland/blob/main/example/hyprland.lua`
- Old hyprlang syntax → 0.54 wiki pages (`wiki.hypr.land/0.54.0/`)

## Lua config mechanics

- `require()` — multi-file configs; separate lua "scope" per file (errors in one file don't kill others). Uses `/` or `.` separators, wildcards, absolute paths supported
- `__require` — original lua require for advanced users; restore with `require = __require`
- `pcall(require, "maybe-nonexistent")` — detect/respond to module load errors
- **Error behavior**: syntax errors refuse reload; runtime errors abort current file; Hyprland type errors continue execution with error popup
- Emergency keybinds on major error: SUPER+Q (terminal), +R (run), +M (exit)
- Loop protection — kills scripts exceeding timeout/limit
- Std libs loaded; config = arbitrary code execution — trust source
- **REPL** — built-in Lua REPL in hyprctl for API exploration
- **LSP stubs** — autogenerated in repo `meta/`, installed `/usr/share/hypr/stubs/`; `.luarc.json` with `workspace.library`

## Core API

```
| Function | Purpose |
|----------|---------|
| `hl.bind(keys, dispatcher, flags?)` | keybinding |
| `hl.dispatch(dispatcher)` | runtime dispatch (functions, conditionals) |
| `hl.dsp.*` | dispatcher table constructors (describe action; fed to bind/dispatch) |
| `hl.config({...})` | config sections |
| `hl.timer(fn, {timeout, type})` | timers (oneshot) |
| `hl.define_submap(name, fn)` | keybind submaps |
| `hl.on("hyprland.start", fn)` | event listeners (autostart) |
```

## Binds

```lua
hl.bind("SUPER + SHIFT + Q", hl.dsp.exec_cmd("firefox"))
hl.bind("SUPER + SHIFT + X", function()
    hl.dispatch(hl.dsp.window.float({ action = "toggle" }))
end)
```

### Flags (3rd arg)

```
| Flag | Effect |
|------|--------|
| `locked` | works under input inhibitor (lockscreen) |
| `release` | triggers on key release |
| `non_consuming` | passes events to window + triggers |
| `auto_consuming` | passes to window if dispatcher fails |
| `mouse` | mouse binds |
| `description` | describe keybind |
| `long_press` | long-press variant |
```

### Key syntax

- Keycode: `code:28` (SUPER + t)
- Mouse: `mouse:272` (LMB), `mouse:273` (RMB), `mouse:276` (MOUSE5)
- Wheel: `mouse_up`/`mouse_down`/`mouse_left`/`mouse_right`
- Modkey-only: TARGET modmask + release flag, e.g. `hl.bind("ALT + ALT_L", ...)`
- Scroll delay: `hl.config.binds.scroll_event_delay`

### Per-device binds

```lua
hl.bind(keys, dispatcher, { device = { inclusive = true, list = { "device1" } } })
```

### Mouse binds

```lua
hl.bind("ALT + mouse:272", hl.dsp.window.drag(), { mouse = true })
hl.bind("ALT + mouse:273", hl.dsp.window.resize(), { mouse = true })
-- drag threshold
hl.config({ binds = { drag_threshold = 10 } })
```

### Global keybinds

```lua
hl.bind("SUPER + F10", hl.dsp.pass({ window = "class:^(com\\.obsproject\\.Studio)$" }))
hl.bind("SUPER + F10", hl.dsp.send_shortcut({ mods = "SUPER", key = "F4", window = "class:^(TeamSpeak 3)$" }))
```
`pass` sends PRESS+RELEASE itself (push-to-talk works). `send_key_state` controls down/up.

### Submaps

```lua
hl.define_submap("resize", function()
    hl.bind("right", function()
        hl.dispatch(hl.dsp.window.resize({ x = 10, y = 0, relative = true }))
        hl.dispatch(hl.dsp.submap("reset"))
    end)
end)
hl.bind("ALT + R", hl.dsp.submap("resize"))
```

### Input remap (kb_options)

```lua
hl.config({ input = { kb_options = "ctrl:nocaps" } })   -- Caps→Ctrl
hl.config({ input = { kb_options = "caps:swapescape" } }) -- swap Caps/Esc
```

## Dispatchers (hl.dsp.*)

Dispatcher tables describe actions — no immediate invocation; contents not guaranteed stable. Fed to `hl.bind()` or `hl.dispatch()`.

### Window selection params

`window object`, regexes (`class:`, `initialclass:`, `title:`, `initialtitle:`, `tag:`), exact (`pid:`, `stableid:`, `address:0x...`), specials (`activewindow`, `floating`, `tiled`). Default: active window.

### General

- `exec_cmd(cmd, rules?)` — `sh -c` execution; rules = window rule effects table
- `exec_raw(cmd)` — no shell
- `focus({ monitor })` — move focus
- `pass({ window? })`, `send_shortcut({mods, key, window?})`, `send_key_state({mods, key, state, window?})`
- `layout(message)` — layout message string
- `dpms({ action?, monitor? })` — monitor on/off (idle-screensaver semantics)
- `event(string)` — send event to socket2
- `global(string)` — activate dbus global shortcut
- `no_op()` — for conditional binds

### Window

- `pseudo({ action?, window? })` — pseudotiling
- `move({ direction, group_aware?, window? })` / `move({ workspace, follow?, window? })` — e.g. `workspace = "special:magic"`
- `swap({ target | next | prev })`
- `center({ window? })`
- `cycle_next({ next?, tiled?, floating?, window? })`
- `tag({ tag, window? })`, `clear_tags({ window? })`
- `toggle_swallow()`, `pin({ action?, window? })`, `alter_zorder({ mode, window? })` (top/bottom)
- `set_prop({ prop, value, window? })` — dynamic window-rule effects, e.g. `no_anim`
- `deny_from_group({ action? })`
- `drag()`, `resize()` (mouse binds); `resize({keep_aspect_ratio})`; `resize({x, y, relative?, window?})`
- `fullscreen_state` — decouples Hyprland state from client state: `-1` current, `0` none, `1` maximized (keeps margins), `2` fullscreen (whole screen)

### Group (tabbed)

- `toggle({ window? })` — make group from active window (i3wm "tabbed" container)
- `next({ window? })`, `prev({ window? })`, `move_window({ forward?, window? })`
- `lock({ action?, window? })`, `lock_active({ action? })`

### Example — exec with rules

```lua
hl.bind("SUPER + E", hl.dsp.exec_cmd("kitty", { float = true, move = {0, 0} }))
```
