# PREFER.OFFICIAL.REFERENCE.md

Official Hyprland wiki first — wiki.hypr.land is the authoritative source.

## Rule

Study claims from official sources before third-party material:
- `wiki.hypr.land` — primary (versioned, latest git by default)
- `hypr.land` — site, news, release announcements
- `github.com/hyprwm/Hyprland` — source, issues
- `wiki.archlinux.org/title/Hyprland` — distro-agnostic secondary (upstream-linked)
- `wiki.nixos.org/wiki/Hyprland` — Nix-specific secondary

Wikipedia, Reddit, blogs — last resort. Cross-check each claim against official reference.

## Order

1. Official wiki page
2. ArchWiki/NixOS wiki (cross-check)
3. Forum/GitHub discussions
4. Third-party tutorials
