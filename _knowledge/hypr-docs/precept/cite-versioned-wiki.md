# CITE.VERSIONED.WIKI.md

Wiki is versioned — cite the version, not just the page.

## Rule

Every note cites which wiki version it reflects:
- Default = latest git commit (check version selector)
- Tagged releases — cite version (e.g. v0.55)
- Check running release with `hyprctl version`

Config syntax changed at 0.55 (hyprlang → Lua). Older notes describing `hyprland.conf` are outdated — flag version in note body.

## Practice

Note header format: `**Source:** URL (date), version` — e.g. `https://wiki.hypr.land/Configuring/ (2026-07-30), latest git`.
