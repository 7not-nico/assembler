# hyprlang.md

Hyprlang is the legacy configuration language of Hyprland, used in `hyprland.conf`.

Since Hyprland 0.55, hyprlang is deprecated in favor of Lua configuration (`hyprland.lua`). Support for `hyprland.conf` is removed in a future release. Old syntax reference: `wiki.hypr.land/0.54.0/`.

The hyprlang library also exists as a standalone project (`hyprwm/hyprlang`) — a config language library. Hyprland's config API is now `hl.*` Lua namespace.
