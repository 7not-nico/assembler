# Acquire

'acquire-acm': download PDFs from ACM DL via Playwright click + download capture
'acquire-assets': download images from JSTOR via Playwright → IIIF UUID → curl → assets.db
'acquire-papers': download raw PDFs from arxiv, Science, and other academic sources
'organize-papers': acquire PDFs → classify by topic → create directories → file-verify
'categorize-papers': organize into findings/{domain}/{subdomain}/ → reindex → prune stale rows
