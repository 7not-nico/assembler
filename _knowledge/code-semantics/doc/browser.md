# Browser

'use-playwright-core': navigate → snapshot → find → click → type → evaluate — core browser interaction for dynamic content
'use-playwright-debug': code execution, assertions, tracing, video, PDF tools — debugging and inspection
'use-playwright-vision': vision-mode mouse coordinate tools — element location via visual targeting
'use-playwright-network-storage': network mocking, storage, auth state management — cookie/localStorage persistence
'use-playwright-ai-mode': interact with Google AI Mode (udm=50) — navigate, chat, extract structured responses
