# PREFER.OFFICIAL.REFERENCE — official documentation first

Always prioritize official language documentation, specification, or reference sources over Wikipedia, tutorials, or secondary sources.

Order of preference:
1. Official language specification or standard
2. Official documentation site (docs.ruby-lang.org, haskell.org, etc.)
3. Official language repository or RFCs
4. Peer-reviewed papers (ACM, NeurIPS, arxiv)
5. Community references only when official sources are unavailable

Wikipedia, blog posts, and tutorials are last resort. They may summarize inaccurately or omit critical detail.
