# WRITE.BROWSER.FIRST — browser reference required before write

Writing or creating any file is prohibited without first opening a Playwright browser session.

Procedure:
1. Open Playwright browser via `playwright_browser_navigate`
2. Research the topic via web search, documentation, or relevant URL
3. Extract findings from the browser page
4. Only then write the file

This applies to all file types: code, documentation, precepts, semantic analyses, and any other artifacts.

A browser snapshot must exist in the session before any write operation is performed.
