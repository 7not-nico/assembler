# ACQUIRE.PAPER.CURL — curl PDFs only

Acquire papers exclusively as PDF via curl.

Do not fetch HTML, text, or other formats. HTML pages are not kept. Only `.pdf` files enter the paper directory.

This applies to academic paper acquisition from arxiv, NeurIPS, ACM DL, Springer, ScienceDirect, and all other sources. If the source does not serve a PDF, do not acquire.
