# CITE.SOURCE.CROSSCHECK — cite sources and cross-check claims

Every claim in a semantic analysis file must cite its source and be cross-checked against the official reference.

Procedure:
1. Identify the official reference for each claim (spec, docs, standard)
2. Cite the source URL or document section inline in the file
3. Cross-check against at least one additional source (implementation source, alternative spec, or peer-reviewed paper)
4. If sources disagree, note the discrepancy
5. Do not assert claims from memory alone — every assertion must trace to a cited source

Sources section at the bottom of each file lists:
- Primary reference (official spec or docs)
- Secondary reference (cross-check source)
- Date accessed
