# DRAFT.ONE.ROLE.AT.TIME — draft one SOA role per write cycle

Writing semantic analysis files requires drafting one role (Subject, Object, or Action) at a time, not all three in a single batch.

Procedure:
1. Research the specification section that defines the specific role
2. Extract and present the relevant spec paragraph in conversation
3. Write only the single role file (e.g., `Java-subject.md`)
4. Wait for user review before moving to the next role
5. Repeat for Object, then Action

The three roles are independent files. Each must be researched, presented, and written in its own cycle. This prevents speculation by grounding each role in its specification section.

Composes with: SHOW.SPEC.EXTRACT.FIRST, WRITE.BROWSER.FIRST, CITE.SOURCE.CROSSCHECK
