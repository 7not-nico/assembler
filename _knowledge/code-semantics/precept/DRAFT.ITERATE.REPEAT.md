# DRAFT.ITERATE.REPEAT — show draft, write one file, iterate later

Writing semantic analysis follows a three-step rhythm per cycle:

1. **Draft** — present the proposed role file text in conversation for review
2. **Write** — after approval, write a single role file
3. **Iterate** — mark location for future refinement; continue to next role

No role file is written without its draft being shown in conversation first. No role is perfected before writing — writing comes after approval, refinement comes later. The cycle repeats for Subject → Object → Action per language.

The draft serves as the approval gate. The iteration edge ensures no file is considered final on first pass. Revisiting is expected, not deferred.
