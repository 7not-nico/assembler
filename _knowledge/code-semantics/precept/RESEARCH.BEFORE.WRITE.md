# RESEARCH.BEFORE.WRITE — research one role completely before writing

Writing a role file (Subject, Object, or Action) requires completing all research for that specific role before the file is written.

Procedure:
1. Identify which role is being written (Subject, Object, or Action)
2. Search web for the relevant specification section
3. Browse into the official spec page via Playwright to verify
4. Present the verified spec paragraphs in conversation
5. Wait for user approval
6. Write only that single role file
7. Repeat for the next role

No role file is written without its own dedicated research cycle. Research for multiple roles is never combined into a single write.

Composes with: BROWSE.AFTER.SEARCH, SHOW.SPEC.EXTRACT.FIRST, DRAFT.ONE.ROLE.AT.TIME, WRITE.BROWSER.FIRST
