## Findings

- **Black screen root cause**: Wayland surface collapse — Vulkan swapchain created at 1x1 on Hyprland. `GraphicsBackend = 0` in `~/.config/ppsspp/PSP/ppsspp.ini` never applied; the log still showed `Vulkan Device created: Intel(R) UHD Graphics 620`. Fix: `SDL_VIDEODRIVER=x11` routes through Xwayland on `:0`; swapchain then real (1872x980, 912x960, 1920x1080)
- **Silent audio root cause**: PPSSPP internal multi-instance silencing — `PPSSPP_ID > 1` sets `iGameVolume = 0` (Core/Config.cpp:1607-1611). `PPSSPP_ID` increments via `shm_open("/PPSSPP_ID")`; a killed process skips `ShutdownInstanceCounter()` (the `shm_unlink`), so the counter persists across crashes (Core/Instance.cpp:187 comment states this). Each pkill'd launch bumped the counter to 7; Tetris booted as instance 7 → internal silence, not a host audio failure. Fix: clear `/dev/shm/PPSSPP_ID` before a fresh launch
- **Trace findings** (tracexec-enriched streams): flat exec tree — single process, no children, one tracer event; thread architecture visible (RenderThread, SAS Thread, SceIoAsync, ScePafJob); font asset gap — `Roboto_Condensed-Regular.ttf` missing; PPSSPP self-healed by deleting `FailedGraphicsBackends.txt` after successful X11 boot
