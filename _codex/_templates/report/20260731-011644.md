## Errors found

```
1. Pipe deadlock — per-query spawn: writing 200KB payload to child stdin while child
   fills stdout → both block forever. Fix: feed stdin from temp file (Bun.file),
   verify proc.exited
2. Bun.delete is not a function — threw silently → fell back to TS (leftover tmp
   files proved bench wasn't using Rust). Fix: fs.unlinkSync + node:fs import
3. semantic-embed queried templates table from templates-vector.db — no such table.
   Fix: open both DBs (reg read-only)
4. ALTER-before-schema ordering — indexes on new columns failed before ALTERs ran.
   Fix: ALTERs first, then schema batch
```

## Findings

```
1. JSON-over-stdin is the wrong transport for heavy vectorization — serialization
   costs more than the offloaded math at every scale tested (0.4-0.8×).
   Rust ANN justified only with binary transport (raw f32) or persistent process
2. Rust core retains value as: correctness-parity reference, batch verb pattern,
   and future binary-transport backend — kept as --rust opt-in, not default
3. Default stays TS in-process — fastest at corpus scale; Rust = opt-in correctness
   twin (identical results verified)
4. Meta field: keyword-dense discriminative lookups (glossary 86.6%, bitacora 83.7%)
   but weak for semantic-ambiguous queries — content-hybrid remains the search default
5. Deadlock lesson: never pipe large payloads to child stdin — temp-file stdin is
   the safe pattern (documented in AGENTS.md)
```
