## Errors found

```
1. FTS5 phrase query matched nothing — whole-phrase "..." has no exact match
   → tokenized OR terms with stopword filter
2. Structural prefix regressed accuracy — PURPOSE text amplifies wrong-file mentions
   → reverted; prefix not beneficial for this corpus
```

## Findings

```
1. Pure semantic beats hybrid on this small corpus (14 templates) — FTS keyword
   precision helps exact-term queries but hurts semantic-ambiguous ones
2. Benchmark targets are themselves questionable: verbatim query → reference-template
   (citations) is arguably MORE correct than expected research-template; test 6's
   expected precept-template contains no keybinding text — informe match defensible
3. Hybrid fusion still valuable as OPTION (--alpha) — kw column shows why a hit won;
   α=1.0 remains default-equivalent
4. α sweep is flat 4/6 across 0.3-0.9 — no single α rescues the 2 genuinely
   ambiguous queries; benchmark refinement needed before further tuning
```
