Neovim notes directory — `notes/` inside the nvim project holds personal notes, scratch buffers, daily logs, and structured documentation managed entirely through Neovim. Each file is a flat markdown document — **no prescribed schema**, **free-form** over frontmatter — keeping the capture barrier at zero. The directory mirrors the conventions of the broader assembler: lowercase, dot-separated filenames for term stubs, and reference files alongside for cross-linking.
