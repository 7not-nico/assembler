**Neovim help index** — authoritative reference for vimdoc, user manual, and built-in help files. Links to key sections: `help.txt`, `usr_*.txt`, `eval.txt`, `options.txt`, and developer documentation.

**Ex commands** — pass commands using `:` prefix in normal mode (`:write`, `:quit`, `:set`). Search with `/` (forward) and `?` (backward). Command-line mode supports tab-completion, history, and ranges.
