# Vim Motions Cheat Sheet

## Vertical
- `j/k` — down/up
- `gg` — first line
- `G` — last line
- `{ / }` — paragraph jumps
- `CTRL-D / CTRL-U` — half page

## Horizontal
- `w/b` — word forward/back
- `e` — end of word
- `0` / `^` / `$` — line start / first non-blank / line end
- `f/t` + char — find / till

## Search
- `/pattern` — forward search
- `?pattern` — backward
- `n/N` — next / previous

## Text objects
- `iw` — inner word
- `i(` / `i)` — inside parens
- `i"` / `i'` — inside quotes
- `it` — inside tag (HTML/XML)

## Marks
- `ma` — set mark a
- `` `a `` — jump to mark a

## Jumplist
- `CTRL-O` — older cursor
- `CTRL-I` — newer cursor
