# Linux Distro Quick Reference

## Packaging families

| Family    | Format   | Package manager |
|-----------|----------|----------------|
| Debian    | .deb     | apt, dpkg      |
| Red Hat   | .rpm     | dnf, yum       |
| Arch      | .pkg.tar | pacman, yay     |
| Alpine    | .apk     | apk            |
| Void      | .xbps    | xbps-install   |
